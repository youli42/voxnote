# 架构

> UI 技术栈：v3.0 起为原生 Java View（`HomeActivity` / `DetailSheet` / `SettingsScreen`），
> 不再有 WebView 界面。UI 只是视图层的一个实现，核心（扫描/存储/解析/用户态）不依赖它，
> 换 UI 不动数据契约。

## 1. 分层与不变量

```
┌─────────────────────────────────────────────────────────────┐
│ 视图层  view     卡片 / 文稿 / 导出 md、jsonl（随时可删可重建）│
│                  原生 View：列表 / 详情 / 设置 / 录音面板      │
├─────────────────────────────────────────────────────────────┤
│ 意图层  intent   编辑、标记、待办（append-only，永不被覆盖）★ │
├─────────────────────────────────────────────────────────────┤
│ 事实层  fact     会话 / 逐句（机器派生，可任意重放、幂等）    │
├─────────────────────────────────────────────────────────────┤
│ 归档层  raw      原始输入快照（日志切片、音频、引擎回包）      │
├─────────────────────────────────────────────────────────────┤
│ 索引层  index    SQLite 缓存（删了能从上面全部重建）           │
└─────────────────────────────────────────────────────────────┘
```

三条不变量，违反任何一条都会在"重新解析 / 换后端 / 多端同步"时丢数据：

1. **事实层可重放**：同一输入重复导入，产出必须逐字节等价（幂等键见数据契约）。
2. **意图层不被覆盖**：事实层重算不得改写、删除用户编辑；编辑只以追加记录存在。
3. **视图层是叶子**：任何视图删掉都不影响数据完整性。

## 2. 模块边界

| 模块 | 职责 | 不做什么 |
| --- | --- | --- |
| `platform` | 设备能力问卷（存储/权限/按键/麦克风/ABI）、版本差异降级 | 不含业务判断 |
| `capture` | `AudioRecord` 采集、分段、VAD、电平、断点保护 | 不做识别 |
| `asr` | 转写引擎抽象（partial/final 流）、结果落库、重跑 | 不做 UI、不决定用哪个引擎 |
| `importer` | 外部来源导入（厂商日志、第三方文件） | 不做实时转写 |
| `store` | 数据契约实现、原子写、迁移 | 不含解析规则 |
| `ui` | 列表 / 阅读 / 编辑 / 设置（原生 View） | 不直接读原始日志 |
| `sync` | 文件级、记录级（LWW） | 不做冲突合并 UI |

**v3.0 的实现映射**（都在 `android/src/dev/voxnote/`）：

| 设计层 | 实现 |
| --- | --- |
| 平台能力 / 存储 | `Storage`（三态 + SAF + MediaStore） |
| 事实层 | `Library` / `MdParser` / `Item` / `plugin.sogou` |
| 意图层 | `State`（`app-state.json`：改名 / 分类 / 标记） |
| 视图层 | `HomeActivity` / `DetailSheet` / `SettingsScreen` / `CardRow` / `SwipeRow` |
| 界面设置 | `UiSettings`（SharedPreferences）+ `LegacySettingsImporter`（一次性迁移） |
| 线程边界 | `DataCenter`（单线程 IO → 主线程回调） |

## 3. 转写引擎抽象（后端切换的核心）

```java
public interface AsrEngine {
    String id();                 // "selfhost-api" / "local-whisper" / "sogou-import"
    String displayName();
    Capabilities caps();         // 语言、流式、时长上限、是否需要联网、预估 RTF
    boolean available(Ctx ctx);  // 当前网络/电量/模型文件是否就绪
    Session open(AsrRequest req);            // 一次转写会话
}

public interface Session extends AutoCloseable {
    void feed(short[] pcm, int len);          // 流式写音频
    void endInput();                          // 声明音频结束
    // 回调：onPartial(text, startMs, endMs) / onFinal(...) / onError(code, msg)
}
```

引擎注册表 + 路由策略，UI 与落库都不感知具体实现：

- `EngineRegistry`：按 id 注册、按能力查询；
- `EngineRouter`：输入（录音 / 导入、语言、时长、网络、电量、实测 RTF）→ 选定引擎；
- **重跑**：每场会话记录 `engine_id`、`engine_version`、耗时、错误码；换引擎/联网恢复后
  可对同一音频重算，结果作为**新版本事实**追加，旧版本保留（便于对比与回滚）。

## 4. 平台能力问卷（可移植性）

启动时填写一份"能力问卷"，上层不猜机型：

| 问题 | 影响 |
| --- | --- |
| `sdk`、是否分区存储 | 文件路径策略、SAF/直读写 |
| 是否有 root | 是否可读厂商库、是否可 evdev 抓键 |
| 麦克风权限策略、后台采集限制 | `capture` 是否需前台服务 / 常驻通知 |
| 按键来源（媒体键 / 焦点键 / 广播 / evdev） | `capture` 触发方式 |
| ABI / 可用内存 / 存储余量 | 本地模型是否可下载、量化等级 |

## 5. 分阶段路线

| 阶段 | 目标 | 验收 |
| --- | --- | --- |
| P0（已完成） | 日志导入 + 卡片 + 逐句文稿 | 与旧模块账本逐句数一致 |
| P1 | 首次启动自动导入、后台常驻、录入新录音即出卡片 | 录完 10 s 内可见 |
| P2 | `capture` 自录 + 文件管理（替代厂商录音） | 拔网也能录、断电不丢段 |
| P3 | `AsrEngine` + 自建 API 后端 + 重跑 | 同一音频可切换后端换结果 |
| P4 | 本地小模型后端（可选下载/量化/空间预算） | 断网可出稿 |
| P5 | 编辑层 + 同步（文件级 → 记录级 LWW） | 两端交叉编辑不丢 |

## 6. 明确不做

- 多端并发实时协作编辑（用 LWW 足够）；
- 为省资源牺牲正确性（如极短去抖窗口换快出稿）；
- 抓取/改写厂商私有数据或注入其进程（导入只读公开可读文件）。
