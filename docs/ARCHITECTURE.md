# 架构

## 1. 分层

```
┌─────────────────────────────────────────────────────────────┐
│ 视图层  view     卡片 / 文稿 / 导出（随时可删可重建）           │
├─────────────────────────────────────────────────────────────┤
│ 意图层  intent   编辑、标记、待办（append-only，永不被覆盖）★  │
├─────────────────────────────────────────────────────────────┤
│ 事实层  fact     会话 / 逐句（机器派生，可任意重放、幂等）      │
├─────────────────────────────────────────────────────────────┤
│ 归档层  raw      原始输入快照（日志切片、音频、引擎回包）       │
├─────────────────────────────────────────────────────────────┤
│ 索引层  index    SQLite 缓存（删了能从上面全部重建）            │
└─────────────────────────────────────────────────────────────┘
```

三条不变量，违反任何一条都会在"重新解析 / 换后端 / 多端同步"时丢数据：

1. **事实层可重放**：同一输入重复导入，产出必须等价（幂等键见数据契约）。
2. **意图层不被覆盖**：事实层重算不得改写、删除用户编辑；编辑只以追加记录存在。
3. **视图层是叶子**：任何视图删掉都不影响数据完整性。

## 2. 模块职责

| 模块 | 职责 | 不做什么 |
| --- | --- | --- |
| 平台能力 | 设备能力探测（存储、权限、按键、麦克风、ABI）、版本差异降级 | 不含业务判断 |
| 采集 | 麦克风采集、分段、电平、断点保护 | 不做识别 |
| 转写 | 可插拔的转写后端、结果落库、重跑 | 不做界面、不决定用哪个后端 |
| 导入 | 从外部来源取历史场次（厂商日志、录音与文稿目录） | 不做实时转写 |
| 存储 | 数据契约实现、原子写、迁移 | 不含解析规则 |
| 界面 | 列表 / 阅读 / 编辑 / 设置 | 不直接读原始日志 |
| 同步 | 文件级、记录级（LWW） | 不做冲突合并界面 |

## 3. 下一步方向

- **转写后端**：自建云服务与本地小模型两种可插拔实现，同一音频可换后端重算；
- **逐句编辑**：把编辑做成追加层落地（改文本、拆分、合并、删除、打星、备注）；
- **同步与自动化**：整目录可拷 → 记录级 LWW；导出清单给 PC / 手机端 watcher；
- **新系统适配**：分区存储、前台服务录音、通知权限的真机验证与降级路径。
- **删除语义**：自录音频真删，导入场次只记墓碑、由用户显式恢复；厂商原始文件永不改写。

## 4. 明确不做

- 多端并发实时协作编辑（用 LWW 足够）；
- 为省资源牺牲正确性（如极短去抖窗口换快出稿）；
- 抓取/改写厂商私有数据或注入其进程（导入只读公开可读文件）。
