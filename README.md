# voxnote

**任何一台 Android 手机上的"录音即笔记"**：按一下录下来，自动整理成能读、能搜、能打点的
日常记录——目标是长成一个 AI 随身笔记，管住你每天说过的话。

在设备本地完成 **录音 → 转写 → 结构化入库 → 阅读/编辑 → 同步/自动化** 的完整工具，
转写后端可插拔（自建云 API / 本地小模型 / 外部导入 / 人工），可移植到其他 Android 设备。

三个部分：

- **App（android/）**：手机上的原生录音与阅读端；
- **服务端（server/）**：自托管 voxnote server——手机把录音同步上去，服务端排队转写，
  Web 控制台负责阅读、逐句修订、任务管理与 AI 对接，转写稿自动回填手机；
- **文档（docs/）**：需求、架构与数据契约。

> 由 `Sogou_S1_transcript`（只做日志提取的 Magisk 脚本模块）演进而来：日志导入从"唯一功能"
> 降级为"数据入口之一"，目标是替代设备自带的录音 App。
>
> **命名**：产品名 `voxnote`（voice + note）。**只保留数据契约里的旧名**——数据目录
> `/sdcard/s1rec/`。改名会牵连已落盘的录音与分类，要动得单独写迁移。

## 能做什么

- **录**：按一下开始、再按一下停止，录完自动出卡片；实时电平可见。
- **存**：录音放哪里可选——公共目录、自定义目录（系统文件选择器授权）、应用私有目录；
  没有权限或写入失败时自动落到私有目录；按 `年.月` 自动建子目录。
- **读**：卡片列表给出标题、待处理原因、摘要、时长、分类、标记与来源；
  点开是全屏详情（从下往上划入）：进度条与暂停固定在页面顶部，
  逐句转写与标记列表是两个并列分页——窄屏左右滑动/点 tab 切换，宽屏（≥600dp）双栏同显；
  每条标记显示其时间点覆盖的那句转写全文，可逐条删除、点行跳播。
- **找**：按标题、摘要、正文搜索；按未转写/转写失败/未分类与各分类筛选。
- **理**：左/右滑各绑定一个分类，滑一下即归类——卡片让开的那一侧显示该方向的目标分类，
  归走的卡片立刻离开当前筛选视图（下一张顶上，不用手动刷新）；详情里可改名、改分类、打点与删标记。
- **删**：卡片右上菜单删除单条；列表可进批量管理，勾选后批量删除或批量归类。
  自录的录音真删文件；导入来的场次只做屏蔽（可恢复），厂商原始录音与日志不动。
- **导入**：可导入设备上已有的录音与文稿；针对特定厂商的导入做成可整体移除的插件，
  核心不认识任何具体设备。厂商日志里带说话人识别的（搜狗 S1 即如此），导入时逐句归属发言人，
  详情页逐行显示"发言人"色片；编号只在那一场会话内稳定。
- **分离**：机器派生的内容可以无限重放，人写的内容（标题/分类/标记）单独保存、永不被覆盖。
- **迁移**：从旧版界面升级时，一次性地把旧设置与分类搬过来。
- **同步**：与自托管 voxnote server 配对后，录音自动上传排队转写，转写稿与控制台改的
  分类自动回填手机（本地自己的转写稿永不被服务器覆盖）；卡片上能看到每场的同步状态
  （已同步/待上传/上传失败），失败的在详情里单场重传；「转文字 / 重新转写」直接触发
  服务器重转写；手机设置页还能选服务器用哪个转写引擎与 Whisper 模型。
- **云端取回**：服务器整库的转写稿自动进本地列表（与本地记录按时间混排，卡片打
  「云端」标），服务器上改过的标题/标签一并同步（本地自己改过名字的不被覆盖）；
  详情页可手动下载原始音频，设置里「自动同步音频」可改为取回时连音频一起下载。

## 构建与安装

首次需要拉工具链（JDK / build-tools / platform，约 300 MB，支持代理）：

```powershell
pwsh -NoProfile -File tools/fetch_toolchain.ps1 -Proxy http://127.0.0.1:10808
```

然后构建 / 安装（已有工具链时用 `-Toolchain` 指 JDK、`-Sdk` 指 build-tools/platforms）：

```powershell
pwsh -NoProfile -File android/build.ps1 -Toolchain <jdk根> -Sdk <android-sdk根>
pwsh -NoProfile -File android/build.ps1 -Toolchain <jdk根> -Sdk <android-sdk根> -Install
```

`-Install` 安装后启动应用。签名用 `android/debug.keystore`（首次自动生成），
反复构建不会换签名、可覆盖安装。

## 服务端速览

单进程 FastAPI + SQLite，无外部数据库依赖；详见 [server/README.md](server/README.md)。

```powershell
cd server
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python run.py            # 控制台 http://127.0.0.1:8787
```

- **转写队列**：DB 为真源，单 worker 顺序消费；引擎边转写边落库，控制台/手机端实时可见；
- **Web 控制台**：记录库（分页/分类/搜索/预览）、逐句修订、任务管理、转写实时出稿、
  播放器、AI 问答入口；hash 路由，刷新/前进/后退回到阅读位置；
- **存储位置可配**：设置页可改音频目录与数据库文件（写 `data/config.json`；
  数据库搬移需重启，界面上有说明）；
- **与 App 配对**：控制台设置页复制令牌；`adb shell am start` 带
  `--es server_url … --es server_token … --es sync_now 1` 一条命令完成配对并同步。
- **安全**：默认绑 0.0.0.0（局域网可连，手机同步即用此通道），设备 API 需配对令牌；
  建议设置 `VOXNOTE_API_KEY` 开启控制台密钥，只本机用可 `--host 127.0.0.1`。

## 设备事实（S1 AI Recorder，实测）

- Android 8.1 / API 27，无分区存储：普通 App 持存储权限即可读写 `/sdcard/**`，**不需要 root**；
- 720×1280 触摸屏，可做阅读与编辑；
- 主体来源是厂商自己落的日志与录音目录：逐句正文只增不删。

## 隐私边界

设备日志、数据库、录音、抓包一律不进仓库（见 [.gitignore](.gitignore)）；
解析产物只写设备本地 `/sdcard/s1rec/`；自托管服务端的数据（音频、SQLite、
可再生的导出镜像）全部落在本机 `data/` 目录，路径可在控制台设置页调整。
